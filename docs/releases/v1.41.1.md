# Seller upgrade 1.41.1 — FREE

Публичный релиз бесплатной версии. exe прикреплён к тегу **v1.41.1**.

## Файл

- `Seller_upgrade_1.41.1.exe` — Windows, портативный onefile (без установки).
- SHA-256: `B64742E39295363C90A2630E2371D98AD397D0C74F7D9574FB3AB188AF5A7E7C`

## Что исправлено

- Устранена ошибка **HTTP 500** при нажатии кнопки печати этикеток на странице
  «Заказы». Дополнительная проверка схемы отправлений больше не может «ронять»
  печать: если Ozon не ответил, запрос уходит с уже отобранными заказами.
- Кнопка переименована: **«Печать этикеток»** вместо «Печать этикетки выбранных».
- Ошибки сохранения PDF теперь показываются понятным текстом, а не как 500.

## Что входит в FREE

- заказы FBS/FBO, статусы, сборка и отгрузка;
- ручная печать этикеток **на одном общем принтере** для заказов и товаров;
- этикетки товаров привязываются к товару и печатаются нужным количеством копий;
- товары, остатки, цены, комиссии;
- продажи за период, статистика по товару, аналитика и себестоимость;
- закупки, настройки, документация, «Про приложение».

Автопечать, планировщик, уведомления, журнал событий, экспорт отчётов,
пакетные операции и второй принтер доступны в PRO.

## Установка

1. Скачайте `Seller_upgrade_1.41.1.exe`.
2. Запустите двойным щелчком — откроется графическое окно.
3. В **Настройки → Учётные данные** введите Client ID и API-ключ из кабинета Ozon.

Подробности — в `docs/user_guide.md`. Ключи Ozon хранятся локально, в дистрибутив
не входят.

## Проверка подписи сборки

```powershell
Get-FileHash .\Seller_upgrade_1.41.1.exe -Algorithm SHA256
```

Сравните вывод с хешем выше.
