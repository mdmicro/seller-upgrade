# Seller upgrade 1.42.1 — FREE

Публичный релиз бесплатной версии. exe прикреплён к тегу **v1.42.1**.

## Файл

- `Seller_upgrade_1.42.1.exe` — Windows, портативный onefile (без установки).
- SHA-256: `4301F02BAB3DEAA7CA0EA4DE067F274AD589BACB1CB76962C7FE38A136D6B407`

## Что нового

- В «Аналитике» появился второй способ расчёта финансового отчёта —
  **«По фактическим выплатам»**. Программа суммирует реальные начисления Ozon
  за выбранный период (зачисления и списания), находит участвующие отправления
  и уже по ним считает оборот, расходы и доход. Старый способ «По дате заказа»
  остался по умолчанию.
- Исправлена ошибка «API Error 0: Network error: 404» при расчёте по фактическим
  выплатам: вместо больше не работающего метода получения транзакций программа
  берёт ежедневные начисления Ozon, которые доступны с текущим ключом.
- В режиме выплат показываются пояснения: число операций и отправлений, сколько
  заказов найдено, суммы зачислений и списаний. Если часть отправлений не найдена
  среди заказов, выводится предупреждение.
- Экспорт отчёта в Markdown сохраняет выбранный способ расчёта (доступно в PRO).

## Что входит в FREE

- заказы FBS/FBO, статусы, сборка и отгрузка;
- ручная печать этикеток **на одном общем принтере** для заказов и товаров;
- этикетки товаров привязываются к товару и печатаются нужным количеством копий;
- товары, остатки, цены, комиссии;
- продажи за период, статистика по товару, оба способа аналитики и себестоимость;
- закупки, настройки, документация, «Про приложение».

Автопечать, планировщик, уведомления, журнал событий, экспорт отчётов,
пакетные операции и второй принтер доступны в PRO.

## Установка

1. Скачайте `Seller_upgrade_1.42.1.exe`.
2. Запустите двойным щелчком — откроется графическое окно.
3. В **Настройки → Учётные данные** введите Client ID и API-ключ из кабинета Ozon.

Подробности — в `docs/user_guide.md`. Ключи Ozon хранятся локально, в дистрибутив
не входят.

## Проверка подписи сборки

```powershell
Get-FileHash .\Seller_upgrade_1.42.1.exe -Algorithm SHA256
```

Сравните вывод с хешем выше.
