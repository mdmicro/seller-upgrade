# Seller upgrade 1.44.0 — FREE

Публичный релиз бесплатной версии. exe прикреплён к тегу **v1.44.0**.

## Файл

- `Seller_upgrade_1.44.0.exe` — Windows, портативный onefile (без установки).
- SHA-256: `DCB130B6B9E1EE24DC9D2A154EA47E090FF790E41809E8D85EC187F4EB68C262`

## Что нового

- В разделе **«Продажи по товару»** чистая прибыль показывается двумя
  способами отдельными строками: **«по дате заказа»** и **«по фактическим
  выплатам»**. По выплатам суммируются реальные начисления Ozon за период,
  по ним находятся заказы, а список заказов берётся с запасом 60 дней назад.
- Добавлены строки **«Чистый доход с единицы изделия»** — чистая прибыль,
  делённая на число проданных единиц, — для обоих способов расчёта. Если по
  выплатам заказы с товаром не найдены, программа предупреждает об этом.
- В разделе **«Заказы»** под виджетом «Сегодня заказано на сумму» появился
  такой же виджет **«Заказано на этой неделе на сумму:»** — с количеством
  заказов и прогнозом чистого дохода. Неделя считается с понедельника.
  Виджет доступен **только в PRO**; в FREE он скрыт.
- Таблица закупок переименована в **«Каталог поставщиков»**. Пункт меню
  «Закупки» и все функции справочника остались прежними.
- Пункты меню **«Аналитика»** и **«Продажи по товару»** поменяны местами:
  теперь «Аналитика» идёт перед «Продажами по товару».
- Документация приложения дополнена объяснением обоих способов расчёта
  прибыли, формулой дохода с единицы и описанием недельного виджета.

## Что входит в FREE

- заказы FBS/FBO, статусы, сборка и отгрузка;
- ручная печать этикеток **на одном общем принтере** для заказов и товаров;
- этикетки товаров привязываются к товару и печатаются нужным количеством копий;
- товары, остатки, цены, комиссии;
- продажи за период, статистика по товару, оба способа расчёта прибыли,
  аналитика и себестоимость;
- закупки, настройки, документация, «Про приложение».

Автопечать, планировщик, уведомления, журнал событий, экспорт отчётов,
пакетные операции, второй принтер и сумма заказов за неделю доступны в PRO.

## Установка

1. Скачайте `Seller_upgrade_1.44.0.exe`.
2. Запустите двойным щелчком — откроется графическое окно.
3. В **Настройки → Учётные данные** введите Client ID и API-ключ из кабинета Ozon.

Подробности — в `docs/user_guide.md`. Ключи Ozon хранятся локально, в дистрибутив
не входят.

## Проверка подписи сборки

```powershell
Get-FileHash .\Seller_upgrade_1.44.0.exe -Algorithm SHA256
```

Сравните вывод с хешем выше.
