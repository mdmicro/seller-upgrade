# Seller upgrade — помощник продавца Ozon на вашем компьютере

**Seller upgrade** — настольная программа для Windows, которая собирает данные из
личного кабинета Ozon и показывает их в одном окне: заказы, товары, продажи,
аналитику продаж, комиссии и себестоимость. Вместо десятка открытых вкладок и таблиц Excel у вас
становится один понятный интерфейс, а этикетки печатаются прямо с компьютера.

Работает **бесплатно, без регистрации и подписки**. Достаточно скачать exe,
ввести ключи Ozon из личного кабинета — и можно работать.

> Не доверяя punto switch я создал открытый проект. Теперь гораздо реже запинаюсь работая на двух языковых раскладках.

## Зачем она нужна

| Было | Стало |
| --- | --- |
| Утром открываете кабинет и вручную проверяете новые отгрузки | Список заказов и статусы уже на главном экране |
| Прибыль считаете в Excel, учитывая комиссии и себестоимость | Программа показывает ожидаемый чистый доход за день |
| Этикетки скачиваете с сайта, потом ищете файл в «Загрузках» | Одна кнопка — и PDF уходит на принтер |
| Этикетку товара нужно то одну, то десять — приходится открывать файл вручную | Этикетка привязана к товару: печать заданного количества в один клик |
| Продажи, остатки и цены разбросаны по разным разделам | Всё в одном окне, переключение одним кликом |

## Что умеет

### 📦 Заказы и отгрузки
Активные заказы FBS и FBO, статусы, работа со сборкой и отгрузкой. Отмечайте
нужные отправления галочками и печатайте этикетки для всей выбранной пачки.
В разделе заказов виден прогноз чистого дохода за день.

### 🏷 Товары и этикетки
Список товаров с ценами, остатками, комиссиями и статусами. Программа печатает
**этикетки заказов и этикетки товаров**. Файл этикетки можно привязать к товару —
например, по артикулу — и в любой момент распечатать нужное количество копий
(от 1 до 100). Удобно, когда этикетку нужно доложить в коробку или перепечатать
испорченную.

В бесплатной версии и заказы, и товары печатаются на **одном общем принтере**,
ничего перенастраивать не нужно.

### 💰 Деньги и аналитика
Продажи за 7, 14, 30 дней, текущий месяц или произвольный период. Статистика по
каждому товару, таблицы FBO / FBS / «Итого», учёт себестоимости и размеров
комплектов. Все цифры — в таблицах, без тяжёлых графиков, поэтому интерфейс
быстро работает даже на слабом компьютере.

### 🗂 Управление
Закупки, себестоимость, настройки принтера и задержки запросов, журнал работы,
встроенная документация и страница «О программе».

### 🎨 Удобства, которые заметны каждый день
- **Портативный exe** — не нужно ничего устанавливать: скачали и запустили двойным щелчком.
- **Окно открывается сразу** — заставка показывает, на каком этапе запуск, вместо пустого экрана.
- **Всё на русском**, тёмная тема по умолчанию, светлую можно включить в статус-баре.
- **Статус-бар** подсказывает, что делает программа: подключение, выполнение задач, запрос к Ozon.
- **Данные остаются у вас** — ключи Ozon и настройки хранятся локально, в облако ничего не отправляется.
- **FREE без подписки** — платные функции просто помечены замком, а не выключены целиком.

## Как начать за 3 минуты

1. [Скачайте последнюю сборку](https://github.com/mdmicro/seller-upgrade/releases/latest) — файл `Seller_upgrade_<версия>.exe`.
2. Запустите его двойным щелчком. Установка не требуется.
3. В **Настройки → Учётные данные** введите `Client ID` и `API-ключ` из личного кабинета Ozon Seller API. [Создать ключи в кабинете продавца](https://seller.ozon.ru/app/settings/api-keys) · [официальная документация Ozon Seller API](https://docs.ozon.ru/api/seller/).
4. В **Настройки → Общие** выберите принтер этикеток — и можно печатать.

**Использование ключей безопасно.** Они хранятся только на вашем компьютере и не
отправляются в облако. При создании ключа в кабинете Ozon укажите параметры
**«только для чтения»** — этого достаточно для просмотра заказов, товаров, продаж
и печати этикеток. Если вы планируете использовать автосборку заказов FBS и смену
статусов (PRO), для этих операций понадобятся права на изменение заказов.
